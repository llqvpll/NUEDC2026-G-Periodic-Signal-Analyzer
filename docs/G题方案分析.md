## 四、信号链设计

### 模拟前端信号流

```
BNC(50Ω) → NE5532缓冲(增益1, 高阻输入)
         → OPA847放大(增益8x)
         → NE5532加法器(叠加+1.25V直流偏置)
         → LT1568/UFA42 LPF(截止频率~600kHz)
         → AD9240(14bit, 0-2.5V输入)
         → STM32F407 (TIM8 DMA采集)
```

### 增益计算

| 输入信号 | OPA847后 | 加偏置后 | AD9240量程利用 |
|----------|----------|----------|----------------|
| 50mVpp | 400mVpp | 0.85V-1.65V | 32% (足够) |
| 100mVpp | 800mVpp | 0.45V-2.05V | 64% |
| 250mVpp | 2000mVpp | 0.25V-2.25V | 80% (最大) |

AD9240: 14bit, VREF=2.5V
- 分辨率: 2.5V / 16384 = 0.153mV/LSB
- 经8x放大后: 0.153/8 = 0.019mV (输入端等效)
- 5mV误差要求 -> 需要精度约262个LSB -> 非常充裕

### DC偏置电路

AD9240输入范围0-2.5V, 但输入信号是交流(正负摆动)
需要叠加1.25V直流偏置, 使信号居中:
- 50mV输入: 0.85V ~ 1.65V (不溢出)
- 250mV输入: 0.25V ~ 2.25V (不溢出)

用NE5532做加法器:
- 输入1: 交流信号 x 8 (来自OPA847)
- 输入2: +1.25V直流 (分压得到)
- 输出: 信号 + 1.25V偏置

```

       Nyquist = 1.25MHz > 1MHz干扰
       -> 1MHz干扰不混叠, 在带内

步骤4: 2048点FFT
       分辨率 = 625kHz / 2048 = 305Hz (满足<=500Hz)
```

- 主要靠数字滤波抑制1MHz干扰
- 模拟LPF要求宽松, 容易实现

**代码修改要点:**

2. 新增FIR滤波函数, 在FFT_Compute之前调用

## 七、关键设计决策

### 决策1: AD9240 vs 片内ADC

选择AD9240, 原因:
- 片内ADC: 12bit, 3.3V -> 0.806mV/LSB, 50mV信号只有62个LSB -> 精度不够
- AD9240: 14bit, 2.5V -> 0.153mV/LSB, 50mV信号有327个LSB -> 精度充足
- AD9240支持10MSPS, 片内ADC最高1.4MSPS(3Cycle), 不够2.5MHz过采样

### 决策2: 固定增益 vs 可变增益

选择固定增益(OPA847, 8x), 原因:
- 50mV x 8 = 400mV -> AD9240有2614个LSB -> 0.019mV精度 -> 足够
- 250mV x 8 = 2V -> 不溢出(0.25V-2.25V加偏置后) -> 不溢出
- 固定增益电路简单, 不需要DAC控制, 可靠性高
- 14bit ADC动态范围足够覆盖50-250mV全范围

### 决策3: Item3干扰抑制方案

选择方案B(过采样+数字滤波), 原因:
- 方案A(纯模拟LPF): 6阶Butterworth fc=600kHz, 1MHz处只衰减25dB
  200mV/17.8 = 11.2mV > 5mV (不满足!)
  需要更高阶或椭圆滤波器, 调试困难
- 方案B(数字滤波): 1MHz在带内不混叠, FIR可做到>60dB衰减
  实现简单(几十行C代码), 可靠性高
  AD9240支持2.5MHz采样, STM32F407有足够算力

### 决策4: FFT点数

保持2048点, 原因:
- CMSIS-DSP arm_rfft_fast_f32已优化, STM32F407执行约5ms
- 2048点在各采样率下分辨率:
  - 500kHz: 244Hz (优于500Hz)
  - 1MHz: 488Hz (满足500Hz)
  - 625kHz(抽取后): 305Hz (优于500Hz)
- 内存: 2048 x 4字节(float) = 8KB, F407有192KB SRAM

## 九、FIR 滤波器代码实现 (题目3核心)

### 9.1 滤波器系数生成

用 Python scipy 生成 64 个 FIR 系数:

```python
from scipy.signal import firwin
import json

# 64-tap 低通, fc=700kHz, Fs=2.5MHz, Blackman 窗
coeffs = firwin(64, cutoff=700e3, fs=2.5e6, window='blackman')

# 输出 C 数组
print("float32_t fir_coeffs[64] = {")
for i in range(0, len(coeffs), 4):
    line = ", ".join(f"{coeffs[j]:.8f}f" for j in range(i, min(i+4, len(coeffs))))
    print(f"    {line},")
print("};")
```

### 9.2 CMSIS-DSP FIR 实现

```c
#include "arm_math.h"

// FIR 实例
static arm_fir_instance_f32 s_fir;
static float32_t s_fir_state[8192 + 64 - 1];

// 预计算的 64-tap 低通系数 (fc=700kHz @ Fs=2.5MHz)
static const float32_t fir_coeffs[64] = {
    // ... 用上述 Python 脚本生成 ...
};

void FIR_Init(void) {
    arm_fir_init_f32(&s_fir, 64, (float32_t *)fir_coeffs,
                     s_fir_state, 8192);
}

// 题目3: 过采样 → FIR → 4x 抽取 → 2048 点
// raw: 8192 点 @ 2.5MHz ADC 原始数据
// out: 2048 点 @ 625kHz (抽取后), 供 FFT 使用
void FIR_ProcessItem3(float32_t *raw, float32_t *out) {
    float32_t filtered[8192];

    // 1. FIR 低通滤波 (阻带 >50dB @ 1MHz)
    arm_fir_f32(&s_fir, raw, filtered, 8192);

    // 2. 4x 抽取 → 2048 点
    for (int i = 0; i < 2048; i++) {
        out[i] = filtered[i * 4];
    }
    // 有效采样率: 2.5MHz / 4 = 625kHz
    // 频率分辨率: 625kHz / 2048 = 305Hz (满足 ≤ 500Hz)
    // 1MHz 干扰: 200mV × 10^(-50/20) = 0.6mV (远低于 5mV)
}
```

### 9.3 题目3 测量流程

```c
void Measure_Item3(void) {
    float32_t raw[8192], fft_buf[2048];

    // 1. AD9240 以 2.5MHz 采集 8192 点 (耗时 3.3ms)
    AD9240_Sample(raw, 8192, 2500000);

    // 2. FIR 滤波 + 4x 抽取 → 2048 点

    // 3. 正常 FFT 流程 (与题目1/2相同)
    FFT_HammingWindow(fft_buf, 2048);

    Calc_TrueRMS(fft_buf); // 真有效值

    // 4. 显示 (波形 1/3 周期 + 频谱 + 数据)
    Display_Waveform(fft_buf, 2048, 625000.0f);
    Display_Spectrum();
    Display_Measurements();
}
```

### 9.4 模拟 vs 数字 FIR 衰减对比

| 方案 | 1MHz 处衰减 | 200mV 残留 | 是否满足 ≤5mV |
|------|------------|-----------|--------------|
| UFA42 6阶巴特沃斯 fc=600kHz | ~25dB | 11.2mV | 否 |
| LT1568 6阶 fc=600kHz | ~28dB | 7.9mV | 否 |

### 10.2 DC 偏置电路

```
TL431 (2.5V 精密基准)
    │
    ├── R1=10kΩ ──┐
    │             │
    └── R2=10kΩ ──┤ → 1.25V (分压点)
                  │
NE5532 加法器:     │
  V_out = V_signal×8 + V_bias
  = (±1V) + 1.25V = 0.25V ~ 2.25V
```

NE5532 加法器接法:
- 同相输入端接 V_bias (1.25V)
- 反相输入端接 V_signal (来自 OPA847)
- 反馈电阻选择使增益为 1 (信号通道) + 1 (偏置通道)

### 10.3 接地规则

1. 星形接地: 所有模拟地汇聚到 AD9240 的 AGND
2. 模拟地和数字地在 AD9240 处单点连接
3. 每个 IC 旁加 0.1μF + 10μF 去耦
4. BNC 屏蔽层接模拟地平面
5. ADC 时钟线远离模拟信号线
6. 电源线走粗线 (≥20mil), 信号线走细线 (8-10mil)
