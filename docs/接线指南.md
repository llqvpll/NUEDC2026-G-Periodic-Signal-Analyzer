## 二、信号链详细接线

### 2.1 信号输入端

| 端子 | 说明 |
|------|------|
| BNC 中心 | 信号输入, 交流耦合(串接1uF电容到UFA42输入) |
| BNC 外壳 | 接模拟地 (AGND) |
| 校准跳线 | AD9959输出经衰减后接到此处, 校准时短接 |

### 2.2 UFA42 低通滤波器 (第1级)

> 功能: 6阶有源LPF, fc=750kHz, 抑制>2.4MHz混叠干扰

| UFA42 引脚 | 连接到 | 说明 |
|------------|--------|------|
| IN | 信号输入 (经1uF AC耦合) | 输入信号50-250mVpp |
| OUT | OPA847 反相输入端 (经Rg电阻) | 滤波后信号, 0V中心 |
| GND | AGND | 模拟地 |
| V+ | +12V | 正电源 |
| V- | -12V | 负电源 |

### 2.3 OPA847 增益级 (第2级)

> 功能: 宽带运放, 反相放大5倍, 带宽>500MHz

```
         UFA42 OUT
            │
            Rg (200Ω)
            │
            ├──────┬────── OUT ──→ AC耦合(1uF) ──→ NE5532 输入
            │      │
            Rf     │ OPA847
          (1kΩ)   │ (反相输入)
            │      │
            └──────┘
                   │
            +1.25V (NE5532产生的偏置, 或单独基准)
            到OPA847非反相输入端
```

| OPA847 引脚 | 连接到 | 说明 |
|-------------|--------|------|
| IN- (反相) | Rg(200Ω) → UFA42 OUT; Rf(1kΩ) → OUT | 反馈网络 |
| IN+ (同相) | 1.25V基准 (或GND, 取决于偏置方案) | 偏置 |
| OUT | (1) AC耦合 → NE5532输入  (2) → TLV3501输入 | 增益后信号, 0V中心, ±125mV~±625mV |
| V+ | +12V | |
| V- | -12V | |
| GND | AGND | |

> **增益验证**: Rf/Rg = 1000/200 = 5. 输入250mVpp → 输出1.25Vpp (±625mV)

### 2.4 NE5532 DC偏置级 (第3级)

> 功能: AC耦合 + 1.25V DC偏置, 将0V中心信号搬到0-2.5V范围供ADC

**半部A**: 1.25V基准产生
```
  +2.5V基准 (ADR421或TL431)
     │
     两个10kΩ分压
     │
     └──→ NE5532 Half-A 电压跟随器 ──→ 1.25V基准输出
```

**半部B**: AC耦合 + 偏置缓冲
```
  OPA847 OUT
     │
     1uF 陶瓷电容 (AC耦合, 隔除DC)
     │
     └──→ NE5532 Half-B (+输入接1.25V, -输入接输出=跟随器) ──→ AD9240 VIN
```

| NE5532 引脚 | 连接到 | 说明 |
|-------------|--------|------|
| Half-A IN+ | 2.5V基准经10k+10k分压 | 产生1.25V |
| Half-A IN- | Half-A OUT (跟随器接法) | |
| Half-A OUT | Half-B IN+ | 1.25V基准 |
| Half-B IN+ | Half-A OUT (1.25V) | DC偏置 |
| Half-B IN- | Half-B OUT (跟随器接法) | |
| Half-B OUT | AD9240 VIN | 0-2.5V信号给ADC |
| V+ | +5V | 单电源供电 |
| V- | GND | |

> **信号范围验证**:
> - 50mVpp输入 × 5倍 = 250mVpp → ±125mV + 1.25V = 1.125V~1.375V ✓
> - 250mVpp输入 × 5倍 = 1.25Vpp → ±625mV + 1.25V = 0.625V~1.875V ✓
> - Item3最坏: 450mVpp × 5倍 = 2.25Vpp → ±1.125V + 1.25V = 0.125V~2.375V ✓ (不饱和!)

### 2.5 AD9240 ADC (第4级)

> 14bit并行ADC, 10MHz最大采样率, VREF=2.5V

| AD9240 引脚 | MCU引脚 | 说明 |
|-------------|---------|------|
| CLK | PC6 (TIM8_CH1 PWM输出) | ADC采样时钟, 频率=采样率 |
| D0 | PE0 | bit 0 (LSB) |
| D1 | PE1 | bit 1 |
| D2 | PE2 | bit 2 |
| D3 | PE3 | bit 3 |
| D4 | PE4 | bit 4 |
| D5 | PE5 | bit 5 |
| D6 | PE6 | bit 6 |
| D7 | PE7 | bit 7 |
| D8 | PE8 | bit 8 |
| D9 | PE9 | bit 9 |
| D10 | PE10 | bit 10 |
| D11 | PE11 | bit 11 |
| D12 | PE12 | bit 12 |
| D13 | PE13 | bit 13 (MSB) |
| VIN | NE5532 Half-B OUT | 模拟输入 0-2.5V |
| VREF | 2.5V基准 (ADR421/TL431) | 参考电压 |
| AVDD | +3.3V | 模拟电源 |
| DVDD | +3.3V | 数字电源 |
| AGND | AGND | 模拟地 |
| DGND | DGND | 数字地 (最终与AGND单点连接) |

> **DMA说明**:
> - DMA2_Stream1 Ch7 (TIM8_UP) → 读GPIOE->IDR (一次性获取D0-D13全部14bit)
> - 单DMA设计, 无需GPIOF
>

## 三、TLV3501 比较器 (辅助测频)

> 超高速比较器 (4.5ns延迟), 用于TIM1输入捕获测频

| TLV3501 引脚 | 连接到 | 说明 |
|-------------|--------|------|
| IN+ | OPA847 OUT (增益后信号, 0V中心) | 信号输入 |
| IN- | GND (或经小电阻到GND, 加正反馈做迟滞) | 零点参考 |
| OUT | PA8 (TIM1_CH1) | 频率脉冲输出 |
| VCC | +3.3V | 电源 (输出0/3.3V逻辑) |
| GND | AGND | |
