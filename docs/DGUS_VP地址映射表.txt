================================================================================
 迪文屏 DGUS II VP 地址映射表 (G题 周期信号测量分析装置)
 屏幕: 7寸 800x480 (DMG80480C070) | 波特率: 921600
 页面: Page0=0.bmp(参数) Page1=1.bmp(波形) Page2=2.bmp(频谱)
================================================================================

一、页面切换

  VP地址    写入值       说明
  ─────────────────────────────────
  0x0084    0/1/2 (u16)  强制切页 (DWIN_SwitchPage)


二、数据变量 VP (MCU → 屏, float=IEEE 754 小端)

  VP地址    类型      内容              所在页   驱动函数
  ──────────────────────────────────────────────────────────
  0x1000    float    基频 f1 (kHz)      0,1     DWIN_WriteFloat → DWIN_SyncParams
  0x1004    float    峰峰值 Upp (mV)    0,1     DWIN_WriteFloat → DWIN_SyncParams
  0x1008    float    真有效值 Urms (mV) 0,1     DWIN_WriteFloat → DWIN_SyncParams
  0x100C    uint16   测量模式 (0/1/2)   0       DWIN_WriteU16  → DWIN_SetMode
  0x1054    float    采样率 (MHz)       0       DWIN_WriteFloat → DWIN_SyncParams
  0x1050    uint16   谐波个数 N         2       DWIN_WriteU16  → DWIN_SyncComponents

三、谐波分量 (Page 2, float 小端)

  频率基址 0x1010, 幅值基址 0x1030, 每次偏移 +0x04

   次数  频率 VP   幅值 VP   驱动映射
  ────────────────────────────────────
   H1    0x1010   0x1030   order[0]=1  → 写这两个地址
   H2    0x1014   0x1034   order[1]=2  → 写这两个地址
   H3    0x1018   0x1038   ...
   H4    0x101C   0x103C
   H5    0x1020   0x1040
   H6    0x1024   0x1044
   H7    0x1028   0x1048
   H8    0x102C   0x104C

  策略: 先清零全部8组, 再按 order[i] 映射填有效分量

四、触摸按键 (屏 → MCU, 保留但本项目键盘为主)

  VP地址    类型    键值        功能
  ──────────────────────────────────────
  0x1060    uint16  0x0001~09  自动上传 (DWIN_ReadTouch 轮询读取, 读后写0清除)

  键值映射: 0x01=Item1 0x02=Item2 0x03=Item3
            0x04=1周期 0x05=3周期 0x06=参数 0x07=频谱
            0x08=分量幅值 0x09=自校准

五、曲线通道 (MCU → 屏)

  通道号    用途        数据格式             驱动函数
  ──────────────────────────────────────────────────
  0x01      波形曲线    [Ch][Count][Y0…Yn]   DWIN_SendCurve
  0x02      频谱曲线    [Ch][Count][Y0…Yn]   DWIN_SendCurve

  曲线数据区 VP: 0x2000(波形), 0x3000(频谱) — 需与 DGUS Tool 控件配置一致
