## 第六步：设置波特率 921600

1. 菜单 **配置 → 系统参数配置**（或 **Config → System Configuration**）
2. 找到 **串口2设置 → 波特率** ，选择 `921600`
3. 其他设置保持默认：
   - 触控变量改变自动上传：**开启**（重要！MCU 才能收到按键值）
   - 背光待机：关闭
   - SD卡接口：开启
   - 22文件初始化：不加载
4. 点 **生成配置文件**

---

## 第七步：生成工程并下载

### 7.1 生成 DWIN_SET 文件

1. 菜单 **生成 → 生成所有文件**（或 **Generate → Generate All**）
2. 等待生成完成，检查 `DWIN_SET` 文件夹下应有以下文件：
   - `0_DWIN_SET.bin` — 系统配置
   - `1_DWIN_SET.bin` — 字库
   - `3_DWIN_SET.bin` — 背景图片
   - `7_DWIN_SET.bin` — 变量配置（数据显示控件）
   - `8_DWIN_SET.bin` — 触控配置（按键）
   - `11_DWIN_SET.bin` — 页面配置
   - `13_DWIN_SET.bin` — 触控配置（V7格式）
   - `14_DWIN_SET.bin` — 变量配置（V7格式）
   - `22_DWIN_SET.bin` — 初始化变量
   - `29_DWIN_SET.bin` — 光标/视频配置

### 7.2 SD 卡下载

1. 准备一张 **FAT32 格式** 的 Micro SD 卡
2. 将 `DWIN_SET` 文件夹内的 **所有 .bin 文件** 复制到 SD 卡根目录
3. 屏幕断电 → 插入 SD 卡 → 上电
4. 屏幕会自动更新（约 30 秒-2 分钟），更新完成后显示新界面
5. 拔出 SD 卡，重新上电

### 7.3 串口下载（可选，不用 SD 卡）

1. 菜单 **配置 → 串口下载**
2. 选择正确的 COM 口，波特率选 `115200`（首次下载）
3. 逐个下载 `DWIN_SET` 文件夹中的 .bin 文件
4. 首次下载 `0_DWIN_SET.bin` 后，屏幕波特率会变为 921600
5. 后续下载需将串口波特率改为 921600

## 常见问题

**Q: 生成后屏不显示新界面？**
A: 检查 SD 卡是否 FAT32 格式，.bin 文件是否在根目录（不能在子文件夹里）。

**Q: MCU 发数据但屏不显示？**
A: 检查波特率是否一致（代码 921600，屏也要 921600）。用串口助手抓包确认 MCU 发出了 `A5 5A` 帧头。

**Q: 触摸按键没反应？**
A: 系统参数配置中 "触控变量改变自动上传" 必须开启，否则 MCU 收不到按键值。

**Q: 浮点数显示不对？**
A: DGUS 的 float 是小端格式（低字节在前），代码中的 `Dwin_WriteFloat` 已按此格式发送。VP 地址和数据类型要对应。

**Q: 曲线显示不出来？**
A: 曲线通道号要与代码一致（波形=1，频谱=2）。曲线控件区域不要被其他控件遮挡。
