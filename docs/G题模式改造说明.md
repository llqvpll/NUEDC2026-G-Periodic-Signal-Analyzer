# G题模式改造说明（2026/08/01）

> 基于原工程《AD DA+AD9959+ADS1256》爆改。**旧功能全部保留未删**：开机进 G 题模式，按 **NumLock** 退回旧菜单，旧菜单按 **[6]** 返回 G 题。
> 未使用迪文屏、未使用阿波罗开发板、未接 AD9959。显示 = 板载 SSD1963 800×480（FSMC），输入 = PS2 键盘。

---

## 一、硬件接线（按接线指南的外部链路，MCU 引脚有调整）

### 模拟链路（不变）
```
BNC → UFA42(750kHz LPF) → OPA847(×5反相) → NE5532(+1.25V偏置) → AD9240
                                └→ TLV3501(过零比较) → PA8
```

### MCU 引脚表（★与指南的差异：数据口改 GPIOG）

| 信号 | 引脚 | 说明 |
|---|---|---|
| AD9240 D0-D13 | **PG0-PG13** | ★指南写 PE0-13，但 PE7-15 被液晶屏 FSMC 总线占用、PE0-6 原接 AD9959，故整组改到 GPIOG（全空、连续、单次 IDR 读取） |
| AD9240 CLK | PC6（TIM8_CH1） | 与指南一致，采样钟 168MHz 整除 |
| TLV3501 OUT | PA8（TIM1_CH1） | 与指南一致，比较器测频互验 |
| AD9959 | **不接** | 本题不用校准源，驱动代码保留未调用 |

> 若你们 AD9240 实际已焊在别的端口：改 `_03_Drive/Drive_AD9240.h` 里
> `AD9240_DATA_GPIO / AD9240_DATA_GPIO_CLK / AD9240_DATA_IDR_ADDR` 三个宏即可，
> **不要选 PE7-PE15（液晶屏占用）**。

## 三、测量原理（对应总体方案）

| 项 | 采样 | 处理 | 分辨率 |
|---|---|---|---|
| Item1/2 | 4096 点 @2MHz (TIM8÷84) | Hanning FFT4096 → 谱峰插值 → GCD 基频 | 488Hz |
| Item3 | 16528 点 @4.8MHz (TIM8÷35) | **127 阶 FIR(fc=600k) + 4 倍抽取** → 同 Item2 流程 | 293Hz |

- **基频**：GCD 最大公约数法 + 最小二乘精修（基波小也不怕，不取最大峰）
- **分量幅值**：精确频率点 Hanning-DTFT（Item3 再按 |H(f)| 修正 FIR 通带衰减）
- **Upp**：整周期窗口 最大 5 点均值 − 最小 5 点均值（抗噪声虚高）
- **Urms**：整周期窗口定义法 √mean(x²)，真有效值
- **波形**：fs≈50×f1 自适应采样（上限 9.88MHz），上跳过零对齐，一屏正好整周期
- **Item3 波形**：对 4.8MHz 原始数据全速率 FIR 后显示（ub 已还原）

## 四、上电验证顺序（建议）

1. 先只接信号源（不接干扰），烧录后应直接进入 G 题界面，自动测一次 Item1。
2. 信号源出 100mVpp/50kHz 正弦 → 看 Upp≈100mV、Urms≈35.4mV、f1≈50kHz。
   - 若波形对折/乱跳 → AD9240 模块输出是补码：把 `Drive_AD9240.h` 里 `AD9240_TWOS_COMPLEMENT` 改 1。
   - 若幅度整体偏差 >2% → 调 `app_gti.h` 里 `GTI_CAL`（= 标准值/显示值 × 原值）。
3. 按 [4] 看 3 周期，按 [6] 看频谱与分量列表。
4. 换题目说明 3 的组合信号（基波+3次+4次谐波）验证 GCD 基频不翻车。
5. Item3：ub 叠加 ≥1MHz/200mVpp 干扰，按 [3]，波形/参数应与无干扰时基本一致。

## 六、资源占用

- 定时器：TIM8(采样钟) + TIM1/TIM2(比较器测频)，与旧功能(TIM3/TIM6等)无冲突
- DMA：仅 DMA2_Stream1_Ch7（TIM8_UP）
- RAM：采集缓冲 33KB 在主 SRAM（DMA 可达）；FFT/信号/谱等约 58KB 在 CCM（0x10000000，CPU 专用）
  ——主 SRAM 约 122KB/128KB，CCM 约 58KB/64KB
- 新增代码不接触 LCD 的 FSMC 引脚、PS2(PA11/12)
- 迪文屏占用 USART1 PA9(TX) PA10(RX)，与旧功能无冲突
