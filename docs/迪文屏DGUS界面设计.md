| VP | 类型 | 内容 | 所在页 | 驱动自动换算 |

## 四、MCU ↔ 迪文屏通信协议

### 写变量帧（0x82）

```
5A A5  [LenL LenH]  82  [VP_H VP_L]  [Data...]
```

- 帧头：5A A5（注意顺序，与常见 A5 5A 相反是 DGUS 特色）
- 长度：小端，= 1(82) + 2(VP) + N(数据字节数)
- VP 地址：大端
- 数据：float 为小端，uint16 为大端

### 发送示例

```
写 f1=50.0kHz(float) 到 0x1000:
5A A5 07 82 10 00  00 00 48 42
                    └─ 50.0f IEEE 754 小端 = 0x42480000

写 mode=1(uint16) 到 0x100C:
5A A5 05 82 10 0C  00 01
```

## 五、驱动实现要点

### 5.1 新增文件

| 文件 | 功能 |
|------|------|
| `_03_Drive/Drive_Dwin.h` | VP 地址宏、float/uint16 写接口、曲线发送、触摸读取 |
| `_03_Drive/Drive_Dwin.c` | 5A A5 帧封装、IEEE 754 小端浮点写入、DGUS 曲线协议 |

### 5.2 驱动设计要点

- **数据格式**：float 控件写 IEEE 754 小端，uint16 控件写大端
- **单位换算下沉**：调用方传原始 Hz/mV，驱动内部 /1000→kHz、/1e6→MHz
- **谐波映射**：先清零 8 组，再按 `order[i]` 次数映射到对应槽位
- **曲线协议**：`[Ch_H Ch_L] [Count_H Count_L] [Y0...Yn]`，单帧上限 200 点
- **SSD1963 屏**：所有现有显示代码一行不改，迪文屏发送在显示刷新点之后追加
